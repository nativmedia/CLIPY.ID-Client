# CLIPY HyperFrames overlays

## Style Prompt
Follow the existing CLIPY caption and thumbnail controls. Use transparent overlays,
fixed text anchors and short, seekable emphasis. The user's font, color, text style,
line limit and position determine the composition.

## Colors
White #FFFFFF is the default text color. Black #000000 supplies outlines and boxes.
The selected accent comes from CLIPY's existing palette, including cyan #33E1FF,
yellow #FFE600 and red #FF3B30.

## Typography
Load the bundled Montserrat Black, Anton, Bebas Neue, Poppins Black or Bangers font
according to the saved project. Preserve the existing measured caption rows.

## Motion
Word highlight, box, underline and glow follow speech timestamps. Pop and fade use
brief local easing. Each cue disappears at its exact end. Emphasis never reflows text.

## Avoid
No background behind the overlay canvas. No layout shifts while words activate.
No external font requests. No source dialogue added to Filming renders.
